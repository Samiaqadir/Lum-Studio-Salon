First time here? Create your admin key.

Open PowerShell in the project folder, generate a private key, set it for the server, then restart the server:

node -e "console.log(require('crypto').randomBytes(32).toString('hex'))" $env:SALON_ADMIN_KEY = "paste-your-generated-key-here" npm start

Keep the generated key private. It is not pre-created or recoverable from the website.
